# Castle Escape sound effects

72 nonvocal effects, all licensed **CC0**. The base 56 recordings are by
**Kenney / Kenney Vleugels (kenney.nl)**. The 16 supplementary recordings improve
crowbar swishes, metal contacts, and glass/ceramic breaks.

- https://kenney.nl/assets/impact-sounds
- https://kenney.nl/assets/rpg-audio
- Download mirror: https://github.com/GeorgeQLe/assets-sfx-combat
- Pinned commit: `9662dc1bed3b06ae753045915f9accfac044c7ce`

Supplementary sources:

- Benjamin Burnes / Abstraction: Organic Wooshes, Classic Swish 1 and 2.
- rubberduck: https://opengameart.org/content/75-cc0-breaking-falling-hit-sfx
- Both packs downloaded from https://github.com/lavenderdotpet/CC0-Public-Domain-Sounds,
  pinned commit `f2b6264f9ab89fabc266914c3654685d68c5a39b`.
- Fission9: https://freesound.org/people/Fission9/sounds/583310/ (Tile Breaking).
- Brsjak: https://freesound.org/people/Brsjak/sounds/623130/ (Ceramic_Break.wav).
- Both Freesound source pages identify CC0; retained sources are public HQ MP3 previews.

Original license texts are included beside this file. `manifest.json` lists every
original URL, source hash, converted-file hash, duration and license. Supplementary
entries include author, source page, role, source filename and processing range.
The original OGG/WAV/MP3 files are retained in `assets/audio/frog-escape/`. These
mono PCM WAVs are edited/resampled copies for local browser playback, not voices.

Implementation, processing and verification: `docs/frog-escape-audio.md`.
