# 奶霸线：第一位面之后的三章误认与终局反转

**状态：后续剧情草案，含作者视角剧透。**本文件安排《奶之救赎：缘起》之后的章节，供后续写中英双语剧本和设计分支。用户确定的核心事实是：奶霸故意造成第一作车祸、主观上想救玩家、真实身份是奶蛙的第二人格；第一位面结束后出场，玩家连续三章把他当反派，身份在大结局揭示。下文关于组织、手甲与事故原理是为故事闭环提出的**可调整方案**。

## 1. 章节位置与悬念规则

| 章节 | 位面与情绪 | 玩家对奶霸的判断 | 章节真正推进的事 |
| --- | --- | --- | --- |
| 第一章《缘起》 | 现实＋第一层迷雾游乐园 | 尚不认识奶霸 | 奶蛙为保护玩家陷入植物状态；玩家救回第一层碎片。 |
| 第二章《冰镜疑凶》 | 第二层冰封镜馆 | 他制造车祸，还想夺走奶蛙的记忆 | 玩家恢复信任碎片，拿到事故证据的一半。 |
| 第三章《血色交易》 | 第三层血肉剧场 | 他与神秘组织交易，利用玩家 | 玩家亲耳听到他承认造成车祸，误会达到最高点。 |
| 第四章《金笼》 | 第四层金丝牢笼 | 他要囚禁玩家、阻止救援 | 玩家挣脱他的阻拦，安抚控制欲碎片；留下无法解释的保护痕迹。 |
| 第五章《无光之下》 | 第五层无光深渊 | 开始怀疑自己的判断，但仍不知真相 | 神秘组织的真实目的浮出水面，追查奶霸与奶蛙的共同来源。 |
| 终章《同一颗心》 | 第六层奶之核心；隐藏纯白摇篮可选 | 揭示奶霸是第二人格 | 玩家面对事故的伤害与保护动机，决定是否让两个人格共同走向救赎。 |

这里的“三章误认”特指**第二、第三、第四章**。第五章可以让玩家怀疑证据不全，却不揭露身份；真正的解释与选择留到终章。第二人格**不等同于第二层的“冷酷碎片”**：六层是奶蛙创伤的心理切面，奶霸是能在现实独立行动的另一个完整人格，第二层只留下与他有关的反射线索。

## 2. 作者掌握的真相（游戏前四章不可直说）

奶蛙与玩家缔结誓约后，神秘组织把一枚抽取标记藏进两人的精神连接。他们要借玩家这位“唯一恋人”的血打开奶之核心，抽取奶蛙的力量；标记启动时，玩家会先被耗尽精神力。奶霸是奶蛙为保护玩家而外化的第二人格，紫色身体是其独立显现的形态，右手金属手甲是暂存、导走精神能量的工具。**手甲不是他邪恶的证据，而是他一直在承担代价的证据。**

事故前夜，奶霸察觉标记即将启动。他尝试拆除失败，时间又不足以带玩家离开，于是操控一辆车制造**近距离的受控撞击**，逼奶蛙在保护玩家时释放足以烧毁标记的能量。车本该偏离玩家，他也预留了制动，但奶蛙的力量反噬比他预计严重，导致植物状态。玩家活下来了，奶蛙却沉睡。**奶霸确实是肇事者；“想救你”不是免除责任的理由。**

奶霸不马上解释身份，有两个动机：他认为过早暴露第二人格会让神秘组织重新锁定两人的同源精神波形；更重要的是，玩家若为了救现实奶蛙而急着强行合并两个人格，尚未安抚的碎片会一起吞噬玩家。于是奶霸选择被恨，持续从旁阻拦危险捷径。他的沉默也是错误，终章必须由他亲口承认并承担后果。

> **待定的机制边界**：组织标记如何植入、奶霸外化的时限、手甲每颗宝石具体对应什么能量，都可在正式剧本中调整；但“奶霸造成事故、原意救玩家、事故伤害真实存在”三点不可改成误会或替身所为。

## 3. 第二章《冰镜疑凶》 / *The Culprit in the Ice*（暂译）

**开场——医院走廊。**玩家刚从迷雾游乐园归来，奶蛙心跳恢复微弱节律。午夜监控里，一个紫色、右手戴金属手甲的身影走进病房，抽走《奶蛙观察日记》新浮现的一页。玩家追到走廊，只看到奶霸回头：“你救回来的是他的一部分。别急着翻下一页。”他关上防火门离开。病房里奶蛙的心率随他的出现短暂变化，玩家以为他做了手脚。

**玩家目标**：找回日记页，在第二层“冰封镜馆”安抚不信任、自我封闭的碎片。镜馆中的镜子只给出**被裁切的记忆**：奶霸站在车祸现场、手甲闪光、奶蛙倒下。碎片因此不停说“不要相信他”。这是真实片段，但不是真相的全部。

**玩法与选择**：玩家可选择追逐奶霸影子、逐块拼合镜片，或先安抚冷酷碎片。追逐最快，却提高精神污染；拼镜片可获得更完整的时间顺序；直接安抚需要玩家回忆现实奶蛙曾尊重自己选择的时刻。无论路线如何，主线都能通过；选择改变之后的证据量与关系数值。

**表面反派行动**：奶霸闯进镜馆，击碎一面保存关键记忆的镜子，带走冰蓝色晶片。玩家认定他在灭证。

**伏笔**：镜子破裂前一瞬，画面边缘显示晶片连接着一条通向玩家心口的细线；奶霸用戴手甲的右手去碰它，晶片亮起，他的手甲宝石反而暗下一颗。玩家若查看完整碎片，还能看见车祸录像中**制动指令早于撞击**。首玩时这些细节可以理解为他在调整计划；终章回看，才知道镜子会抽取玩家精神力，奶霸切断了它。

**章末**：冷酷碎片被安抚。现实奶蛙的手指更明显地动了一下；另一边，奶霸右手出现同位置的细小裂痕。他把日记页放在医院楼梯间，没有带走。页角写着：“别把所有看见的都当成完整的记忆。”玩家仍认为这只是敌人的诱导。

## 4. 第三章《血色交易》 / *The Crimson Bargain*（暂译）

**制作状态**：第三章已在本地实现为独立可玩章节。本层主角按用户指定命名为**奶粉**，采用粉色身体、浅色肚皮、绿色眼睛的参考形态，语音复用奶蛙原声。本层仍承载破坏冲动；奶粉的愤怒不改变现实奶蛙的阳光性格。正式双语台词与分支以 `src/chapter-three-story.ts` 为准，角色与素材见 [第三位面奶粉资料](third-layer-naifen.md)。

**开场——虚假的援手。**一家自称研究异常生命的机构提出治疗奶蛙，并交给玩家车祸的另一段录像：奶霸在路口操作控制器。玩家终于有了直接证据，开始主动追捕他。组织提供的设备能让玩家更轻松进入第三层，但会在界面上悄悄增加精神污染。

**第三层“血肉剧场”**把爱与破坏欲做成反复上演的舞台。每幕都让玩家看见奶霸像在指挥演员，仿佛他早就安排了奶蛙的痛苦。玩家需要分辨真实记忆与舞台排演：真正的记忆会保留雨夜和早餐等生活细节，伪造场景只复制最激烈的情绪。

**表面反派行动**：奶霸在现实中把一个发光的“碎片容器”交给组织人员，换回被扣留的玩家物品。玩家听到他亲口说：“车是我引来的。”他不解释，甚至说“你恨我，比较安全。”这句承认必须保留，确保终章不是把肇事责任推给别人。

**伏笔**：组织人员走后，奶霸立即破坏交易用的容器；地上残留物是假的。玩家获得的物品里夹着一张不属于组织的路线图，恰好避开会令精神力归零的舞台门。第二段车祸录像虽然证明他操控了车，却也显示车头在最后一秒偏离玩家所在的位置。画面要足够短，第一次游玩仍可以怀疑他只是在保全计划。

**玩法与选择**：玩家可以交出真碎片换取“治疗”，也可以验证路线图后用假容器交换。错误选择进入污染更高的暗线，但不要让组织在此公开真面目；正确选择保护碎片并使第三层安抚成功。玩家对奶霸的敌意可以继续升高，剧情不强迫玩家相信他。

**章末**：奶霸被玩家当面质问，只回答：“我做的事不会变成没做过。先活到能问我的那天。”玩家认定他既傲慢又危险。玩家转身后，他抹去组织设备上记录玩家血液波形的资料；读者只能看到一阵失控火花。

## 5. 第四章《金笼》 / *The Gilded Cage*（暂译）

**制作状态（2026-10-09）**：用户指定第四层主角为奶神（Naishen），以提供的金黄色红白披布三视图为身份标准，采用油画质感。当前版本按用户反馈改为通俗叙事、十二片画作拼图及完成后的用户视频，16 个双语节点与三个结局。下文仍为终章伏笔草案，不代表本章所有内容已经实现。正式代码见 `src/chapter-four-story.ts`；原始草案与实现有细节差异，当前角色／玩法见 [奶神制作记录](fourth-layer-naishen.md)。油画预热已上传 GitHub（`47885e1`），本次按用户授权上传完整可玩版本。

**开场——进入第四层的代价。**金丝牢笼把“保护”扭成“控制”：每条金线都声称只要玩家留下，奶蛙就能醒来。现实中的奶霸在入口前抢走血誓媒介，封住一扇门，对玩家说“今天你不能再往前”。玩家经历了三次阻拦，确信他就是要囚禁自己。

**玩家目标**：不接受“为了爱必须失去自由”的假命题，找到让碎片自己打开笼门的方法。玩家可强行挣脱、利用前三章收集的细节谈判，或暂时绕路寻找纯白摇篮的线索。三条路径都能安抚第四层，但精神力、污染和后续信任不同。

**表面反派行动**：奶霸用手甲挡住玩家的血之通路，并毁掉笼门上最醒目的一枚钥匙。玩家以为他宁愿奶蛙永远沉睡，也不愿让自己接近核心。

**伏笔**：玩家回顾界面可发现，奶霸挡路前精神力只剩下一点；挡路后玩家的精神力上升，而他的手甲又暗了一颗宝石。被毁的“钥匙”背面刻着组织的抽取标记。医院监测屏上，奶蛙的心跳与奶霸受伤的一瞬出现同一个异常节律；玩家可能猜他是克隆体、同族或窃取力量的人，但不能据此直接得出第二人格答案。

**章末——误会顶点。**组织放出一份看似完整的调查报告，证实奶霸策划了车祸，却删去制动时间和组织标记。玩家可以选择保留或烧掉奶霸留下的路线图；这影响终章能否取得完整证据，不影响“他确实造成车祸”的事实。玩家发誓要亲自阻止奶霸，第三个误认章节结束。

## 6. 第五章与终章的反转

**第五章《无光之下》**开始拆解误会，但仍不报出奶霸身份。玩家找到组织的原始实验记录，发现他们需要“唯一恋人”的血进入奶之核心，并长期把奶蛙当成可抽取的能量源。记录中同一生命被标出两道精神波形；组织还在追捕紫色个体。玩家第一次意识到奶霸未必属于组织。绝望碎片逼玩家在“一个人去死，另一个人醒来”的选项中选择；正确道路是拒绝牺牲式捷径，保留两人的自由。此章结尾只留下一个问题：**奶霸为什么能和奶蛙共享波形？**

**终章《同一颗心》**进入奶之核心。组织试图把玩家当作通道，强行抽取全部碎片。奶霸为阻止装置耗尽手甲能量，紫色外形开始变得透明；玩家同时在奶蛙记忆中看见第二个“我”诞生的瞬间：当它第一次害怕自己无法保护被爱的人时，分出一个愿意承担危险决定的人格。奶霸是这个第二人格在现实的外化，并非同族、克隆或组织造物。

在完整事故记忆里，玩家同时看见奶霸操控车辆、提前制动、让车头偏离玩家、奶蛙自发挡在身前、超出预期的力量反噬。奶霸亲口解释组织标记，承认自己未经同意把玩家和奶蛙置于险境：“我想救你，但我没有权替你决定承受什么。”玩家可以愤怒，真相不要求立刻原谅。

最终选择要有代价而非一句“原谅”即可通关：

1. **救赎结局**：玩家先切断组织的抽取通道，再让奶蛙与奶霸共同面对事故和创伤，允许两个人格在明确边界下整合。现实奶蛙苏醒，仍保有阳光开朗的一面，也知道自己有一个曾做错事的第二人格；玩家与它的关系需要重新建立信任。
2. **隔绝结局**：玩家抹去奶霸以求立刻唤醒奶蛙。奶蛙醒来，但失去承担恐惧的那部分自己，后续位面的防御随时可能复发。它不是“杀掉坏人就皆大欢喜”的结局。
3. **被夺结局**：玩家把所有碎片交给组织换取奶蛙醒来，短暂成功后发现自己沦为新的通道，精神世界坍塌。
4. **隐藏真结局**：若玩家保留三章的关键证据、在第五章拒绝牺牲捷径，并找到“纯白摇篮”的纯真碎片，就能在整合前清除组织标记。奶蛙和奶霸的记忆都得以保留，玩家也活下来；奶霸仍需面对他造成事故的责任。

## 7. 伏笔与回收清单

| 埋设位置 | 初次理解 | 终章回收 |
| --- | --- | --- |
| 第一章事故中的彩色金属反光 | 不明袭击者的武器 | 奶霸手甲；他确在现场。若旧图片没有此细节，可在台词或监控画面补充，不强行改旧素材。 |
| 第二章车祸录像的提前制动 | 他操控车辆时临时改变计划 | 他预留避让，目标是触发防护能量，不是撞死玩家。 |
| 第二章碎镜后暗掉的宝石 | 使用力量的普通消耗 | 手甲替玩家承受了抽取。 |
| 第二章与第四章同步的伤痕／心跳 | 克隆、同族或窃取力量 | 两个身体共用精神来源。 |
| 第三章亲口承认“车是我引来的” | 反派自白 | 真自白；反转改变动机，不推翻事实。 |
| 第三章被破坏的交易容器、被抹的血液记录 | 内讧或灭证 | 奶霸在误导组织、保护玩家的血。 |
| 第四章被毁钥匙上的组织标记 | 奶霸阻挠救援 | 所谓捷径是组织准备的抽取入口。 |
| 日记对奶霸时而警告、时而引路 | 日记被敌人篡改 | 日记来自同一潜意识，不同人格留下的提示互相冲突。 |

**写作约束**：前三个误认章节都要给玩家足够理由恨奶霸，也都至少留一条可回看的反向证据。关键身份揭示不依赖玩家是否收集全部可选线索；可选线索改变的是理解深度和真结局资格。奶霸造成事故的事实、现实奶蛙的阳光性格、第一层碎片的病娇特征均保持不变。

**双语实现**：章节标题英文目前是工作译名。正式制作时，玩家可见台词、证据名称、选项和结局必须与中文同步写成英文；反转伏笔在两种语言中保留相同信息量，不能由某种译法提前泄露身份。
