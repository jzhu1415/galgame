# 网站审查与修复 · 2026-10-02

## 范围

首页、章节详情、第一／第二／第三章的网页流程、恋爱 DLC、存档、剧情树、音频与分镜加载。第二章只修改章节页面、检查点及预览／回放，3D 镜馆内部由另一个任务审查。保留工作区中已有的剧情、语音与其他任务修改。

## 已修复

| 问题 | 修复 |
| --- | --- |
| 禁用存储可能使启动或操作中断；存档容量不足会抛错 | 共用安全存储接口，失败时保留本次会话状态并显示实际保存情况；解锁也可在本次页面会话内完成，不伪造视频观看次数 |
| 每句台词重复写入相同存档 | 去重相同内容的同步写入；另一标签页更改存储时使缓存失效 |
| 第一章根据历史推算检查点；探索场景保存时可能把途中状态当成首次入场 | 访问记录与检查点分离，实际进入节点时记录状态；旧访问记录需要重新抵达后才能回放；不再在打开预览或加载存档时创造检查点 |
| 第二章跳转只改阶段，带入当前线索，重玩后丢失后续解锁 | 使用与第一章相同的原生思维导图、拖动缩放与确认框，单独保存累计节点／结局；回放恢复首次抵达的线索、路线和碎片台词位置 |
| 损坏存档可能显示空白台词、重复回忆，或绕过调查／路线门槛 | 校验节点、数组与历史，限制台词索引；资源去重；第一章回忆、第二章线索、第三章幕后路线与 DLC 日期门槛均在恢复时检查 |
| 快速切图残留旧图，过期加载回调覆盖新请求，图片失败后卡住 | 第一章／DLC 共用渐变切图，最多保留两个图层；忽略过期回调；失败时保留旧画面，DLC 可回退场景图；预加载去重并遵守节省流量设置 |
| 切换语言或重绘时角色原声重播；DLC 回顾随当前行李改变文本 | 保留当前语音位置／跳过状态，原声不依赖语言；记录当时是否使用薄毯；第三章相同分镜／立绘复用原节点 |
| 弹窗旧关闭事件影响新弹窗、空白区域被误判为遮罩、输入／长按推进剧情 | 使用弹窗实例判断、遮罩边界检查和焦点恢复；弹窗开启时暂停自动推进；过滤键盘重复与表单焦点；第二章文字剧情支持空格／Enter |
| 第一／二章链接不支持直接进入，第三章返回后刷新丢失章节 | 三个章节统一读写 `?chapter=`，返回详情保留所在章节 |
| 首页一次加载所有章节；慢网络载入完成后可能抢回已退出的页面 | 后续章节／DLC 的代码与样式按需加载，有返回与重试；过期载入结果不挂载游戏 |

修复说明已合并到 `src/release-notes.ts` 的最新中英文更新弹窗，与同期章节详情页更新一起展示；保留首页与详情页入口，不写入章节存档。
