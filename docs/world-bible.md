# 《奶之救赎》世界观设定（当前版本）

本版依据 2026-09-25 的最新命名与性格修订：**全项目的角色统一称奶蛙**。现实奶蛙阳光开朗；第一层精神世界中的奶蛙碎片才呈现阴暗病娇的一面。此前以两个名称区分现实与精神世界、以及现实角色已经表现出囚禁和威胁行为的写法，均由本版取代。

**英文正式名：`naiwa`**。角色及项目的英文名称统一采用该拼写。

## 1. 双层世界与连接

| 层面 | 设定 | 第一作中的作用 |
| --- | --- | --- |
| 表世界 | 普通都市与打工人生活；奶蛙以阳光、开朗、愿意照顾人的面貌与玩家相恋，都市中有超自然暗流。 | 相遇、恋爱、朋友劝告、神秘组织制造的车祸与奶蛙沉眠。 |
| 里世界 | 奶蛙的精神世界，由六个核心层级和一个隐藏位面构成；每层有人格碎片与心理防御。 | 玩家首次进入“迷雾游乐园”，看见现实奶蛙不曾表现出的被抛弃恐惧与阴暗占有欲。 |

以**血为钥匙、誓约为通道**。奶蛙认定玩家为唯一恋人后，玩家才有潜入资格；第一作中，玩家将血滴在陷入植物状态的奶蛙额头，进入第一层。“血誓戒指”已在道具设定中提出，是否在第一作登场、如何获得及是否为潜入必需品尚未确定。

## 2. 奶蛙与玩家

**奶蛙的本质**：奶蛙是以“被爱”为锚点的情感凝聚体／精神生命。没有锚点时可能流浪、衰弱；创伤和黑暗冲动主要藏在精神世界，不作为日常现实人格的行为方式。现实里的奶蛙坦率、乐观、体贴，会主动做饭、打扫、表达喜欢，也尊重玩家的选择和私人空间。

它的力量仍来自爱、执念与不安。遭遇致命威胁时可能失控爆发，肉体无法承受，进入冰冷、无法行动的**植物状态**。这不改变它在现实线的既定性格。精神世界是其心理防御系统；第一层的奶蛙碎片承载“害怕被抛弃”，会以病娇方式扭曲对玩家的爱。

**玩家**：普通人类，是现实奶蛙的恋人、被爱者与拯救者。玩家不靠战斗，而靠选择、安抚和解谜前进。现实中的信任与陪伴能成为精神世界的线索；错误选择与精神力耗尽会导致死亡结局。

## 3. 精神世界法则与状态

| 法则 / 状态 | 当前规则 | 待细化 |
| --- | --- | --- |
| 血之通路与誓约 | 唯一恋人资格、血滴额头与誓约共同构成进入条件。 | 誓约是否需要仪式；戒指的获得和用途。 |
| 精神力 | 每次移动、每个选择都会消耗；耗尽则玩家脑死亡。 | 初始值、消耗、恢复和界面提示。 |
| 人格碎片 | 每层一个核心碎片；安抚后融入玩家，现实奶蛙恢复一点。 | 碎片融入后的长期影响。 |
| 心理防御 | 玩偶、怪物和扭曲场景可攻击入侵者。 | 各层遭遇与解谜线索。 |
| 猜疑值 | 由现实互动累积的关系不安影响里世界的危险程度与视觉强度。现实奶蛙不会因此直接变成监视、威胁玩家的性格。 | 阈值、镜头变体和谜题变化。 |
| 精神污染度 | 玩家受里世界侵蚀的程度；影响 UI、选项字体，可能开启危险分支。 | 阈值、降低方式和结局条件。 |
| 《奶蛙观察日记》 | 奶蛙潜意识留下的引导道具，随进度浮现字迹。 | 页面内容和提示力度。 |

同一存档在中英文界面下共用状态与结局判定。精神污染可以改变 UI 呈现，但选项在两种语言下都应可读、可操作。

## 4. 六层与隐藏位面

第一层的性格定位已由本次修订确定；后续位面名和人格细节仍为**暂定**，不可据此把现实奶蛙写成病娇。

| 层级 | 位面名 | 奶蛙人格碎片 | 核心主题 | 第一作范围 |
| --- | --- | --- | --- | --- |
| 第一层 | 迷雾游乐园 | 哭泣的奶蛙：阴暗、病娇，害怕玩家离开 | 被抛弃恐惧、扭曲的依恋 | 抵达并安抚 |
| 第二层 | 冰封镜馆 | 冷酷的奶蛙 | 不信任、自我封闭 | 仅埋伏笔 |
| 第三层 | 血肉剧场 | 疯狂的奶蛙 | 破坏冲动 | 仅埋伏笔 |
| 第四层 | 金丝牢笼 | 执念的奶蛙 | 边界与控制 | 仅埋伏笔 |
| 第五层 | 无光深渊 | 绝望的奶蛙 | 自我厌恶、毁灭 | 仅埋伏笔 |
| 第六层 | 奶之核心 | 真我 | 所有碎片的整合 | 仅埋伏笔 |
| 隐藏 | 纯白摇篮 | 纯真的奶蛙 | 最初本心、真结局钥匙 | 是否出现线索待设计 |

**第一层已确定的空间特征**：废弃游乐园、永远下雨、失控旋转的木马和诡异的小丑玩偶。现实奶蛙的明快形象在这里发生反差：碎片一边哭着求玩家留下，一边通过防御机制试图困住玩家。安抚后雨停，现实奶蛙出现微弱恢复；第一作不会解开全部层级。

## 5. 现实威胁与伏笔

- **神秘组织／袭击者**引发车祸，迫使奶蛙保护玩家、力量失控，继而陷入植物状态。组织可能在追捕奶蛙，但身份与动机未定。
- **社会压力**包括朋友对跨常理恋情的疑虑。奶蛙会先坦诚沟通；玩家的隐瞒与回避仍可累积关系不安，影响精神世界，而非直接触发现实中的威胁行为。
- **流浪原因**仍是伏笔；追捕、遗弃或精神世界溢出都是未确认方向。

## 6. 核心冲突与主题

- 现实中的温暖与内心的阴影属于同一个奶蛙；拯救它要理解被压住的恐惧，同时保护彼此的自由和边界。
- 第一作的惊悚来自**反差**：玩家信赖的开朗恋人，在精神世界第一层变得阴暗、病娇且害怕失去。
- 接纳人格碎片不等于认同伤害或囚禁。玩家以安抚和选择帮助奶蛙面对创伤；错误的靠近方式会激活防御机制。
- 系列主线是逐层潜入、安抚碎片，最终在核心层走向救赎或毁灭；隐藏位面关联真结局。

## 8. 与第一作剧情的衔接

- [第一作分镜提示词](origin-storyboard-prompts.md)按本版角色性格执行。旧稿中现实线的囚禁、翻手机、威胁朋友、小黑屋结局已废止。
- 接受奶蛙的告白，才满足唯一恋人资格；拒绝则是体面的错过结局，不进入精神世界。
- 现实线的宠溺、回避、朋友劝告仍构成选择分支，但表现为信任与沟通的差异。第一层的危险由隐藏的创伤及玩家此前的选择共同决定。
- 奶蛙第一层的阴暗病娇形态只在精神世界呈现；结尾现实奶蛙仍处于植物状态，未来苏醒后的性格不预设突变。
