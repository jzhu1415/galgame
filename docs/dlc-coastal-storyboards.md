## 接入方式

`src/romance-dlc-visuals.ts` 记录每个节点按台词位置切换的分镜。同一句台词在读档、回看与切换语言后仍显示同一画面。保留环境开场和淡入切换，每一段角色发言都有人物出镜，四张约会手账封面也改为角色图。手机裁切按各图的人脸位置调整，保留已有对白布局。

没有找到海玻璃的支线不展示海玻璃；拥抱只在玩家询问、角色同意后显示；星空投影只用于选择观星的支线；清晨通用特写不加入未选择的保温壶、录音机或薄毯。素材载入失败时回退到原环境图。

PNG 原图保留在 `assets/images/`，网页 WebP 在 `public/images/`。实际生图提示词、参考路径及用途记录在 `dlc-coastal-image-prompts.json`。原先未传参考图的试稿没有接入项目。

检查：`npm run check:romance-dlc` 覆盖全剧情分支、三种结尾、全部台词分镜、图片存在性及角色出镜条件；`npm run build` 检查项目构建。遵循项目规范，不主动进行浏览器验收。
