# 冰馆水晶分区加载

日期：2026-10-19。基于远端 `8112959`，保留冰封奶蛙等已有功能。

## 行为

- 地面、墙面、连接通道与浮空水晶由五个确定性区域工厂生成，进入地图块范围时才创建几何和实例对象；离开范围后移出场景并释放对应缓冲，不保留隐藏的完整模型缓存。
- 与墙地面共用 16 米地图块和 `VIEW_RADIUS`：窄屏为 1，宽屏为 2。水晶沿用现有房间批次，区域边缘保留 3 米余量，覆盖倾斜晶体尖端与浮空旋转。它们在接近房间入口前已经加载。
- 区域卸载同时移除动画条目与画质重建闭包；共享材质及细裂纹的小型公共几何保留到镜馆退出。几何所有权在画质替换时转移，避免遗漏旧缓冲或重复释放。
- 返回房间重新生成相同布局，浮空晶体使用绝对时间恢复运动；不会累计实例数量或重复创建灯。
- 新区域使用当前画质的几何、密度与折射设置。两盏嵌入灯定位到新创建的壁面水晶，共享反射材质在模型尚未加载时就登记到环境反射管理器。
- 存档定位后立即同步水晶区域，不等待玩家走动。核心角色模型、物证、路线、存档与手机操作保持原有逻辑。

## 检查

`npm run check:ice-streaming` 覆盖真实初始几何分配减少、远处对象未创建、离开时的几何与实例释放、多次往返的常驻缓冲上限、几何位置确定性、浮空实例数量、相邻区域预载、横向卸载，以及画质与嵌入灯恢复。

原几何检查显式加载完整目录，继续验证全馆密度、法线、通行空间与保守包围体。另检查环境反射材质提前登记、完整探索、剧情回放、浏览器缓存返回、手机输入、画质选择、核心水晶角色与碰撞、中英文更新弹窗，并运行构建。依照项目偏好未打开浏览器，未声称真机帧率提升。
