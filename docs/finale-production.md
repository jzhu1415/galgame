# 第五章 · 终章制作记录

2026-10-10，延续用户优化的宣传页，完善合并终章、前半段角色取景及战后分镜。主角仍为奶蛙及玩家；牛来、香蕉猫、奶豆均为反派组织成员，黑化肥嘟嘟为后续决战对手。

## 实际内容

- 单章 69 个双语节点、5 个结局，深渊追踪 → 连续档案 → 实验区争论 → 现实研究楼 → 核心记录 → 牛来争执 → 本体苏醒 → 城市影片 → 发现腰斩 → 奶霸献祭 → 奶蛙复活 → 战后选择。
- 中段三个转运结果改为连续过场；跨幕不清空线索、不恢复精神力、不返回章节详情。首页仅保留第五章终章入口；旧 `?chapter=6` 跳转第五章。
- 视频前与香蕉猫、肥嘟嘟、牛来的对抗以争论展开，每处只保留两个关键回应；不出现挥拳、躲闪或肉搏。账本、录像、值班表和核心记录连续展开，减少重复调查菜单。可选摇篮回忆仍完整保留。
- 奶霸在后半段亲口解释第二人格与车祸责任；动机不免除责任。保留纯白摇篮调查，但仅凭旧线索不能越过现场核验。
- 影片后城市成为废墟，玩家发现奶蛙被腰斩；奶霸告别、献祭全部意识，将奶蛙救回。此过程在线性主线上必经，结束后才开放最终选择。奶霸无备份、无复活、无后续对白；组织三人始终为反派。清晨城市不会自动复原。
- 黑化递进补入深渊、实验区与屋顶争论：肥嘟嘟相信组织拼接的录像，主动答应外接装置；见到原片后害怕承认自己的参与，停机后仍坚持控制奶蛙。装置影响不替它免除选择的责任；没有新增战斗动作或对战图。
- 组织成员先通过正在执行的操作露面，再进入现场：牛来在医院监护与广播中安排转运、最后持同一份许可出场；香蕉猫用抽泣掩饰封门与改路线；奶豆先在完整录像里压住报警并签名，随后在实验区守备用开关。三人的分工、后续对白和原有立绘衔接，不增加调查菜单。
