# 第五章 · 终章制作记录

2026-10-10，延续用户优化的宣传页，完善合并终章、前半段角色取景及战后分镜。主角仍为奶蛙及玩家；牛来、香蕉猫、奶豆均为反派组织成员，黑化肥嘟嘟为后续决战对手。

## 实际内容

- 单章 69 个双语节点、5 个结局，深渊追踪 → 连续档案 → 实验区争论 → 现实研究楼 → 核心记录 → 牛来争执 → 本体苏醒 → 城市影片 → 发现腰斩 → 奶霸献祭 → 奶蛙复活 → 战后选择。
- 中段三个转运结果改为连续过场；跨幕不清空线索、不恢复精神力、不返回章节详情。首页仅保留第五章终章入口；旧 `?chapter=6` 跳转第五章。
- 视频前与香蕉猫、肥嘟嘟、牛来的对抗以争论展开，每处只保留两个关键回应；不出现挥拳、躲闪或肉搏。账本、录像、值班表和核心记录连续展开，减少重复调查菜单。可选摇篮回忆仍完整保留。
- 奶霸在后半段亲口解释第二人格与车祸责任；动机不免除责任。保留纯白摇篮调查，但仅凭旧线索不能越过现场核验。
- 影片后城市成为废墟，玩家发现奶蛙被腰斩；奶霸告别、献祭全部意识，将奶蛙救回。此过程在线性主线上必经，结束后才开放最终选择。奶霸无备份、无复活、无后续对白；组织三人始终为反派。清晨城市不会自动复原。

## 美术与声音

- 六张带真实透明通道的角色立绘、十张地点背景。
- 39 张非对战 CG 与特写：调查物件、组织成员、奶霸解释、本体苏醒、战后情绪及开场深渊补充镜头。
- 无光深渊开场使用七张分镜，包括既有信标图和新增入场远景、断桥俯视、监控屏、柱后身影、肥嘟嘟情绪特写与日记物件近景，随对白切换。
- 用户明确指定“不生成对战照片”：对抗节点使用既有地点与立绘，决战主体只播放提供的原片。之前生成的交锋图未复制到项目、未接入代码；新补图均为非对战内容。
- 原始 PNG 在 `assets/images/finale-*.png`；网页 WebP 在 `public/images/finale-*.webp`。逐张对照原始身份；参考、用途与实际提示词见 [原始素材记录](finale-image-prompts.json) 与 [CG 记录](finale-closeup-prompts.json)。新增 CG 使用内置 `image_gen`。
- 前半段立绘向画面中部移动并放大，桌面与手机竖横屏分别布局；下半身允许被底部对白遮挡，脸部位于工具栏下方。柱后肥嘟嘟、监控台香蕉猫与抱档案奶豆的 CG 采用更近取景，原图不变。
- 新增战后发现、腰斩、献祭、复活四张分镜，参考与提示词见 [战后素材记录](finale-sacrifice-prompts.json)。
- 再补六张特写：肥嘟嘟争论中的表情、奶霸告别、右手消散、空护腕与日记、奶蛙含泪、奶蛙抱日记。实际传入原始角色与既定场景参考，逐张核对；PNG/WebP 路径、参考用途与完整提示词见 [特写素材记录](finale-memory-closeup-prompts.json)。
- 献祭再补六张近景：右手护腕贴胸口、金色生命光流入胸腹、肩膀消散、奶霸最后的眼神、空护腕旁最后一粒紫光、奶蛙重新睁眼。告别最后一句进入贴胸镜头，献祭八句各有分镜切换，复活首句接睁眼特写；原有献祭全景与回忆继续保留。双角色镜头同时传入两者原始参考，附件镜头保留奶霸原始护腕参考；修复细节未通过身份核对的版本未复制或接入，实际参考、用途、提示词与最终路径见 [献祭特写记录](finale-sacrifice-closeup-prompts.json)。
- 复用八张前章旧图：雨夜相遇、一起做早餐、窗边合照、写日记的夜晚、两人份晚餐、雨夜车灯、金色门前的奶霸与记忆画廊。原图不修改；随对应对白切入，中英文“回忆 / MEMORY”标识与轻微旧照片色调区分过去，同一节点内切回当前场景。“看图”显示原图及回忆标题。献祭之后奶霸仅出现在明确标注的旧图中；回忆不改变存档、路线与声音时序。复用路径、内容哈希与切入位置见 [回忆镜头记录](finale-memory-shots.json)。
- “看图”按钮打开完整当前画面；查看不推进剧情。CG 场景不叠加重复立绘，角色特写与环境分镜逐句切换。
- 350 个中英文逐句朗读文件覆盖旁白、日记、玩家与组织成员。奶蛙、奶霸轮换四段原声；肥嘟嘟沿用第二层原声，可能与字幕不逐字对应。独立 `finale-manifest.json` 不修改其他章节朗读记录。
- 再生成声音：安装 `edge-tts==7.2.8` 到所用 Python 环境，再运行 `npm run generate:finale-tts`；根据当前对白哈希缓存，仅重生成变化的文件。
- 战后从废墟开场至各结局沿用宣传页主题曲 `/audio/bgm/naiwa-finale-theme.m4a`。默认音量 12%，对白播放时降至 7%；淡入并在循环结尾淡出。逐句推进及语言切换不重启音乐。总声音开关同时控制音乐；面板及后台暂停，关闭面板或返回前台接续；重看影片、回放到战前或离开章节释放音乐。

## 存档与剧情树

统一存于 `naiwa-chapter-five-v1` 与 `naiwa-chapter-five-progress-v1`。历史独立终章存档与真实检查点可只读迁入第五章，首次实际进入或确认回放才写入；合并后的新存档有 `mergedFinale` 标记，重新开始不会再恢复旧独立章节。旧战后存档缺少新主线标记时，从废墟开场继续，保留真实状态与解锁；不虚构献祭经历或回放检查点。

复用第一章点阵画布、SVG 连线、节点、缩放、拖动与原生弹窗。详情页与游戏内同图；未抵达节点 `???` 灰显，旧访问无快照仅展示访问状态。首次抵达保存精神力、线索、路线，回放保留解锁图鉴。稳定根节点支持全屏、Esc、遮罩与入口焦点恢复。

## 检查

- `npm run build`
- `npm run check:finale`：所有节点与结局可达、争论选择与连续档案、跨幕状态不重置、影片幂等、献祭及复活必经门槛、首次抵达回放、完整地图、39 张 CG 与八张旧图路径和哈希、回忆回切与只读状态、献祭分镜覆盖与角色消失后的连续性、朗读哈希。
- `npm run check:finale-preview`：预览不写存档、不创建音频；确认后保存真实检查点；旧终章合并及重开行为。
- `npm run check:finale-bgm`：战后播放门槛、低音量与对白压低、连续播放、循环、暂停与静音、自动播放重试、战前回放与释放。
- `npm run check:release-notes`、`check:chapter-promo`、`check:route-preview`。
- 第一、三、四章剧情及第四章拼图、影片、声音与尾声相关检查。

遵循用户偏好，不主动打开浏览器；本地构建与逻辑检查后由用户刷新验收。当前记录只表示本地制作完成，不表示已上传或部署。
