# 项目审查与前端修复 · 2026-10-12

本轮审查覆盖首页、五章详情与游戏控制器、海岸番外、统一剧情树、弹窗与全屏、媒体生命周期、存档迁移、镜馆通信与触控、素材和构建配置。检查采用源码审查、真实函数的事件模拟、剧情与素材脚本、生产构建和 npm 依赖审计。

现有 27 项检查在修改前全部通过。继续审查发现了下面 12 个未覆盖的边界问题，已修复，并增加或扩展对应的回归检查。工作区已有的终章分镜、旁白、故事与统计更新保留。

| 问题 | 触发方式与原因 | 修复 |
| --- | --- | --- |
| 终章读取异常存档时报错 | 历史 JSON 的场景字段不是字符串，或路线字段不是数组。迁移代码在规范化之前直接调用字符串与数组方法。 | 迁移先验证字段类型；预览在内存中恢复可用状态，不写入存档，也不捏造历史检查点。 |
| Esc 取消拼图时离开章节 | 全局返回快捷键在捕获阶段抢先处理，拼图来不及取消选中或拖动。 | 全局导航在冒泡阶段尊重已处理事件。拼图通过文档事件处理取消，拖动后的兼容点击也不会重新选中。 |
| Esc 退出视频时离开剧情 | 视频进入原生全屏后，返回快捷键仍点击章节返回按钮。 | 原生视频全屏下保留浏览器的 Escape 行为，退出播放器后继续停留在剧情。 |
| 镜馆面板关闭后焦点丢失 | “关闭”按钮先清除面板引用，随后关闭事件因引用不匹配而跳过焦点恢复。 | 面板状态清理与入口焦点恢复分开处理；明确关闭、原生关闭与卸载都按当前状态处理。 |
| 切换语言后无法接着键盘操作 | 页面替换使旧按钮失去连接；设置入口在重绘后还可能位于已收起的更多菜单内。 | 查找等价的新按钮恢复焦点；若它在关闭的菜单中，改为定位可见的菜单开关。 |
| 返回主页时试图聚焦隐藏入口 | 从详情页页尾切到另一章，再返回主页时，主页仍保留原来选中的预览面板。返回代码却找新章节的隐藏入口。 | 保留主页选择与阅读位置；入口不可见时定位当前选中的章节标签。 |
| 手机页内定位被顶部栏遮住 | 首页采用固定的 88px 滚动偏移，无法覆盖刘海安全区域或更高的工具栏。 | 使用工具栏实际高度加留白定位，角色入口与普通页内链接共用此规则。 |
| 后台视频被算作完整观看 | 浏览器可能在隐藏标签页暂停媒体事件，返回时一次性报告后续播放进度，计数器误判为前台连续观看。 | 切换可见性时结算之前的区间、重置采样时钟并在后台暂停视频；正常前台暂停后仍可续看。关闭弹窗移除监听。 |
| 快速关开主题曲后静音 | 淡出还没结束时重新开启，音频仍在播放，旧判断直接返回，音量继续降到零。 | 重新开启会取消停止任务，并恢复淡入，无需等待音频先暂停。 |
| 旧播放错误影响新播放 | 先前的自动播放拒绝可能在新一次播放之后返回，取消当前淡入并重新挂上手势监听。 | 每次播放使用请求编号，关闭和卸载使旧请求失效；旧错误不修改新一次播放。 |
| 宣传页离开后仍有待执行动效 | 首次布局与数字计数动画没有纳入清理，只取消了普通滚动帧。 | 记录并取消首帧、计数帧和媒体淡入帧；已卸载的观察器通知不能重新启动任务。 |
| 减少动态效果无法即时恢复 | 开页时把系统偏好写入了固定的“支持动效”判断，后来关闭减少动态效果也无法启用动效。 | 分开检查浏览器能力与当前系统偏好，后续切换立即更新页面。 |
