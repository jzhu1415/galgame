# 主页项目介绍 · 2026-10-10

本次主页修改范围：`src/home-page.ts`、`src/home-page.css`、`src/main.ts` 的主页渲染与清理、更新说明，以及对应功能检查。保留其他未提交的剧情与素材修改。

## 视觉与内容

依据用户最新反馈，主页使用**黄白风格**，作为整个项目的介绍页。保留制作过程时间线，替换此前过于接近终章的暗色、城市全屏开场。开场使用黄纸形状、白色留白与大幅奶蛙；章节采用浅色图文分栏，不沿用终章电影式暗色叠图布局。

故事介绍、旧照片、奶蛙与奶霸两张角色卡、五章预览与制作时间线组成长页。依据后续防剧透反馈，角色区只保留奶蛙与奶霸，不展示其他角色的身份、阵营或对战关系；奶霸只作简短介绍。主页不放决战画面、腰斩或献祭分镜。所有图片复用现有 WebP，本次没有生成新图片。

## 可以操作的内容

- 点击奶蛙，在四条欢迎与浏览提示间切换，不播放角色声音。
- 奶蛙与奶霸的档案支持点按、方向键、Home / End；展开小档案，再定位其对应章节的预览。
- 五章各有真实章节介绍入口。预览支持点按、方向键、前后按钮和手机横向滑动，每章可以展开玩法介绍。
- 三张故事照片可以打开完整大图；制作工作台可以查看当前节点的大图。
- 七个制作节点支持日期滑杆、前后切换、场景画面 / 制作手记切换，以及时间线全部展开 / 收起。指针或键盘定位日期时，工作台同步更新。
- 阅读进度条、轻微鼠标视差、标题出现、照片反馈与滚动显现。减少动态效果时显示静态内容。

主页面的角色、章节、时间节点、工作台视图与滚动位置仅保存在本次运行的内存快照中；切换语言或从章节返回时恢复。浏览不修改任何游戏存档、解锁、线索或路线，不自动进入章节。

大图采用挂在稳定 `#app` 根节点的原生弹窗，兼容全屏。支持关闭按钮、Esc、点击遮罩关闭，并恢复入口焦点；已有弹窗时禁止叠加。卸载时清理监听、动画帧、观察器与大图。
