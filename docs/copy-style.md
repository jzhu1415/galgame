# 《奶之救赎》文案校订

2026-10-02：按用户“文案太 AI”的反馈，参考 [Humanizer 中文版](https://github.com/holygeek00/humanizer-zh-cn/blob/main/SKILL.md) 和上游 [Humanizer](https://github.com/blader/humanizer/blob/main/SKILL.md)，用于本轮校订。此处记录游戏写作的具体取舍，外部 skill 的公文、营销规则不直接套进剧情。

## 角色说话

- 现实奶蛙开朗、爱操心，也会犯傻、失望、开玩笑。体贴通过相处表现，少说心理咨询式的“你可以……”“你不必……”。
- 主角是普通打工人。日常说话省事，危险时先顾眼前；不要每次回应都像准备好的演讲。
- 奶粉容易冲动，说话带刺，求助时也有犹豫。安抚之后仍会生气，不能突然变成讲道理的老师。
- 奶霸少解释，答话生硬。留住身份和动机伏笔，不用格言代替他眼下要做的事。
- 研究员的客气带着催促和回避；日记给足可用线索，不替玩家分析主题。

## 旁白和选项

旁白写人物做了什么、看见什么、卡在什么地方。已经有牵手、留照片、收车票这样的动作，就在动作处停下，不追加“这次旅行的意义”。保留精神世界必要的怪异意象，也保留日常的小细节，不把所有句子磨成同一种短句。

选项写玩家接下来要说的话或做的事。线索、代价和门槛照常交代，避免在选项里预先评判哪个回应更成熟。中英文同时修改，英文按对话习惯写，不硬跟中文语序。

## 英文独立审校

中文润色后，英文仍需按场景单独读一遍。日常对白使用自然缩写和具体用词，但不要给所有角色套同一种俏皮口吻：奶蛙热心、爱开玩笑，奶粉冲动，奶霸生硬，研究员客气又回避。旁白保持过去时，长短句随动作变化，不靠连续句子碎片制造紧张。

英文正文中的角色名用 `Naiwa`，页面品牌名仍用 `naiwa`。奶蛙与奶粉沿用正文主要使用的 `it/its`；奶霸、奶鼠和研究员用 `he/his`。身份不清或多人同场时直接重复名字，避免为了不重复而使读者猜指代。

线索不能只追求顺口：保留时间码间隔、制动与撞击的先后关系、谁说话，以及尚不能确认的动机。标题、选择和功能提示用英语习惯表达，专有地点名与路线 ID 保留。本轮另行参考英文原版 Humanizer，并同步生成英文逐句配音。

例如，奶蛙找到海玻璃时，把“普通的东西因为两个人一起找到而变得特别”改为“跑了这么远，就这么一小颗啊……还挺好看的。你看。”保留发现和喜爱，去掉总结。奶粉抓着吊线时，用“你是不是也嫌我烦了？”说出担心，比直接阐释接纳与自主更贴合人物。

## 接入校验

只改文本，不改节点 ID、句子索引、角色归属、状态数值、路线条件和分镜时点，以兼容存档、回放与画面。改动有逐句配音的文本时运行 `npm run generate:tts`，核对音频 manifest 的文本哈希。检查完整分支、更新说明和构建；按项目偏好，由用户刷新进行视觉验收。
