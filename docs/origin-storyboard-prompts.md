状态：**文字预案，尚未生图**。本版以[当前世界观](world-bible.md)为准：所有场景的攻略对象统一称**奶蛙**；现实奶蛙阳光开朗，第一层精神世界的奶蛙碎片才阴暗病娇。此前现实线的小黑屋、翻手机和威胁朋友情节已改写。

角色与项目的英文正式名统一写作 **`naiwa`**。

## 1. 统一画面规则

- **叙事视角**：玩家是奶蛙的恋人。优先用玩家第一人称；需要同框时只露出玩家的手、肩或模糊背影，不预设性别与脸。
- **形象一致性**：现实与精神世界是同一奶蛙，均参考现有三视图的体型、颜色与五官。现实线使用明快神态；第一层碎片通过目光、姿态、光线与局部失真表现阴暗病娇，不随意改变角色基本轮廓。
- **情绪节奏**：雨夜相遇虽狼狈，但奶蛙主动乐观；同居日常明亮、轻松；车祸后转为沉痛；进入第一层才出现强烈的占有与恐怖反差。
- **画面规格**：横向 16:9 网页 Galgame 背景/事件 CG；画面下方约 25% 留给对话框。需要时再制作透明立绘和移动端裁切。镜头编号代表叙事节点，不要求每镜都生成独立图。
- **双语适配**：图片不绘制任何文字、字幕、UI、选项、日记字迹或水印。中英文台词、选项和道具提示均由网页叠加。同一美术素材服务两种语言。
- **状态变体**：现实选择形成的关系不安影响第一层画面的危险程度。精神污染影响网页 UI 与选项字体；在两种语言下仍须可读。死亡结局可用遮光、影子、空间崩塌表现，不要求血腥特写。

### 单镜共用前缀

> 参考上传的奶蛙正面、侧面、背面三视图，保持黄色圆润身体、浅色腹部、绿色眼部、短手和渐深的手足等可见特征，以及同一角色的比例与轮廓。制作《奶之救赎：缘起》的横向 16:9 Galgame 插画/背景，清楚的前中后景与电影感构图。玩家视角优先，画面下方保留对话框安全区。画面不含文字、标志、按钮和水印。

将此前缀与下表单镜提示词合并。现实线与精神世界沿用同一三视图，主要改变表情、动作和氛围。下表“网页叠加／分支”不是生图提示词。

结构只锁定已有主干。A02 分支改变关系不安、第一层危险与后续对话；具体阈值和更多结局待玩法设计。现实线没有病娇式囚禁结局，第一层才出现阴暗占有与危险结局。
