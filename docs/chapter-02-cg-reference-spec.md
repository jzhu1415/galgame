# 第二章 CG 参考约束

第二章插画使用内置 imagegen 生成或编辑。下列参考图的角色造型优先级高于文字描述和已有 CG。

## 角色

- **奶鼠／第二位面形态**：以 [`second-layer-form-source.png`](../references/second-layer-form-source.png) 为主，三视图 [`second-layer-form-turnaround.png`](../references/second-layer-form-turnaround.png) 补足侧面与背面。光滑黄色身体、浅黄腹部、明显不对称的两只粗长圆耳、大棕色椭圆鼻、白眼圈中的棕色眼睛、短手、宽大的坐姿足、短而弯曲的粗尾巴。不要画成有绒毛、胡须、粉色内耳或细尾巴的兔子／老鼠。
- **奶霸**：以 [`naiba-source.jpg`](../references/naiba-source.jpg) 为主，三视图 [`naiba-character-turnaround.png`](../references/naiba-character-turnaround.png) 补足角度。光滑紫色圆润身体、浅色腹部、绿色圆眼、细小笑口、短肢，**右手**佩戴镶彩色宝石的深铜色金属手甲。不要改成披甲人形、国王、长袍人、长角或长耳角色。
- **玩家**：普通人类男性。第一人称镜头可出现手，镜面中不要擅自加入未设定的女性角色。

## 场景

冰封镜馆沿用 Poolrooms 地图：低平顶、重复的浅色方形瓷砖墙柱与地面、浅水、矩形荧光顶灯和不锈钢池梯。冰晶、裂镜和冷色光作为第二层附加元素。不要转成哥特城堡、大教堂、拱顶或幻想城市。

## 本批镜头

`chapter-02-hospital` 和 `chapter-02-journal` 属于现实医院；`chapter-02-elevator`、`chapter-02-ice-hall`、`chapter-02-cg-cold-mirror`、`chapter-02-crash-memory`、`chapter-02-gauntlet`、`chapter-02-cg-shattered-mirror`、`chapter-02-thaw` 属于第二层。每次补图时分别用角色原图／三视图作为身份参考，用已确认的瓷砖镜馆图作为场景参考，并检查人物是否保持同一造型。
