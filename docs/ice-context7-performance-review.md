# 冰馆性能审查 · Context7

日期：2026-10-16；对照提交：`c573449`；本地依赖：Three.js `0.185.1`。

## 资料与范围

实际调用 Context7 的 `resolve-library-id`，选择官方库 `/mrdoob/three.js`，查询物理材质／折射、多次渲染与 PMREM，以及静态矩阵／实例资源。Context7 返回的是官方开发分支资料，随后逐项核对本地 `node_modules/three` 的 r185 实现，没有升级依赖或直接照搬其他版本 API。

- [WebGLRenderer](https://github.com/mrdoob/three.js/blob/r185/src/renderers/WebGLRenderer.js)：折射背景和最终画面会分别绘制不透明物体，因此同一物证 Reflector 可在同一帧重复采样。
- [Reflector](https://github.com/mrdoob/three.js/blob/r185/examples/jsm/objects/Reflector.js)：`onBeforeRender` 内会使用虚拟相机再次渲染场景；仅降低镜面分辨率不能消除重复场景遍历。
- [Object3D](https://github.com/mrdoob/three.js/blob/r185/src/core/Object3D.js)：静态本地矩阵和世界矩阵可分别关闭自动更新，但必须先计算正确的世界变换，且不覆盖动态对象。
- [WebGLObjects](https://github.com/mrdoob/three.js/blob/r185/src/renderers/webgl/WebGLObjects.js)：实例矩阵等缓冲依赖 `InstancedMesh.dispose()` 事件释放，仅释放几何与材质不足够。

## 实施

1. **复用同帧镜面采样**：物证镜面按当前画面帧号和最近一次相机身份缓存。在折射背景与最终画面使用同一个视角时复用；下一帧照常刷新。若水面反射相机插入，返回主视角时重新采样，避免使用错误的投影画面。没有降低平衡／高画质的镜面尺寸或更新频率。
2. **冻结完成的静态地图块**：地图块加入场景、完成世界矩阵后，关闭块内本地和世界矩阵自动更新。相机、灯池、水面、物证拾取动画和浮空水晶均在这些树之外。新进入的地图块仍按原流式逻辑生成；边界、射线和通路不变。
3. **释放实例缓冲**：离开镜馆时释放八批浮空水晶与三套物证螺钉的实例缓冲，每个对象仅释放一次；浏览器缓存返回仍保留原场景。
4. **修正极低档帧调度漂移**：使用固定期限推进渲染时钟，避免浮点边界和迟到回调不断重启间隔。切换画质或暂停状态时立即重置期限；错过的期限直接跳过，不积压补帧。默认画质、菜单 12 帧预算和后台跳过绘制的行为保留。

## 验证与取舍

`npm run check:ice-performance` 覆盖重复采样、逐帧刷新、二级相机切换、实例释放、静态地图变换／边界／射线、60／120／144 Hz 帧调度、菜单预算和后台跳过绘制。另运行全部冰馆交互、路线、探索、画质、反射、缓存返回、剧情回放检查及中英文更新弹窗检查，然后构建。

审查了灯池、PMREM 缓存和物理材质：已有的按房间缓存、亮度防抖、画质预算和折射采样比例继续使用。没有通过减少正常画质灯光或关闭正常画质折射换取数字，也没有改用单面渲染破坏完整晶体的内部表现。遵守项目偏好，没有启动浏览器或真机视觉验收。
