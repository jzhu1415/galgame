# 手机剧情画面 · 2026-10-20

目标：减少手机阅读时的遮挡，保留完整对白和操作，不压缩字到难以阅读。

- 第一章、第三章、第四章、终章、海岸番外的工具栏收成一行。原来的按钮保留在展开菜单中；支持键盘进入、Esc 收起与焦点返回。点击画面收起菜单时不会顺带推进剧情。
- 第二章沿用自己的菜单，移动端收起重复的阅读工具栏与重玩、回顾、剧情树快捷入口，对应操作仍可从菜单打开。镜馆小地图、摇杆、触控视角、附近物证操作保持原实现。
- 对白保留 16px 正文，缩减姓名牌、标题、段间和操作区留白。普通手机对白区最多约 44% 屏高；横屏适当加宽并限制在约 55%。长对白、角色介绍和选项完整保留，可以滚动，不裁掉文本。
- 第三章回到大背景加叠加立绘的手机舞台，减少重复的独立小图框对空间的占用。章节颜色、终章战后破损装饰继续保留。
- 收起界面的看图模式只改变当前场景的 DOM 状态；恢复按钮始终可用。进入时关闭自动／快进，空格、Enter、方向键和点击画面不会在下面推进剧情；退出看图不会自动恢复快进。切换章节／重建场景后恢复正常界面。
- 菜单与恢复按钮保持至少 44px 点击高度，兼容安全区和原有全屏。宽度超过 800px 且不属于小屏横屏时不启用紧凑布局；桌面上的新增控制条隐藏。

实现：`src/mobile-scene-ui.ts`、`src/mobile-scene-ui.css`，由主入口初始化。工具收纳保留原按钮及事件处理，不替换各章的存档、剧情树或阅读逻辑。

检查：`npm run check:mobile-scene-ui` 覆盖展开／收起、焦点、看图防误触、自动模式关闭、语言切换、重复渲染、桌面恢复和清理。按项目约定不主动开启浏览器，完成构建和相关剧情检查后由用户刷新验收。
