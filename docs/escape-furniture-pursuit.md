# 2026-10-20 · 家具材质与追捕

## 材质

原先桌椅、柜子与床架复用 `wood`／`darkWood`，因此与木地板共用拼板纹理；厨房与浴室台面复用 `stone`，出现与墙石相同的灰缝。

- 单独增加浅橡木、木制收边、胡桃木柜体与白色大理石材质。厨房两段台面为白色灰脉大理石；桌椅、书桌与长凳采用浅木；衣柜、书柜、抽屉和床架分别使用连续木纹与配色。
- 标准画质使用共享 128 像素颜色纹理，高画质按族共享 512 像素颜色／法线／粗糙度图。木纹沿构件长轴，大理石有细灰脉和光滑表面；降档恢复原材质图并释放高档纹理。
- 原有木地板、石墙、灰泥、地砖、屋瓦的纹理和配色没有修改。用变更前记录的颜色／法线／粗糙度 SHA-256 快照核对五组建筑纹理，逐字节保持一致。
- 地下室家具按用户后续要求单独使用深色木材。最深处两组原本只有绿色圆柱装饰的实心高柜改为深木开放酒架，24 个酒瓶／玻璃杯使用游戏已有真实物品模型与拾取、投掷、破碎系统。没有任务门槛，建筑地板与墙面仍不受此换材质影响。

## 追踪方向

复现：奶蛙刚收到声音、已向声音规划路线时，在反方向看见玩家，原先仍受 0.9 秒路径刷新冷却限制。30 FPS 下最初 0.3 秒反而远离玩家约 1 米。

- 首次看见及重新看见玩家时清除旧路线与无关的临时退让目标。可见目标移动时缩短规划间隔，明显反向时立即重规划。门、家具与其他障碍仍按实体绕行。
- HUD 区分当下看见、追向最后出现的位置与通透形态的气息追踪。隐藏后不再读取玩家新位置来更新普通视觉追捕。

## 后院水池

池内玩家仍通过真实视线检查；错误在于 A* 只把庭院当作统一高度，不能表达入口浅台阶，且旧入口对奶蛙的体宽和网格偏窄。

- 仅给池底与入口台阶标记可步行地形，寻路采用这些实体顶部高度。池壁、柱子和家具仍是障碍。
- 适当加宽浅台阶与池壁开口，兼容玩家和奶蛙的实际半径。实际直立／倒立奶蛙在 30／60／144 FPS 都能走入池内并捕获玩家。
