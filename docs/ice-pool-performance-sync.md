## 已同步

- `reference-rendering.js`：DPR 上限与总像素预算同时约束主画面及后处理。高/平衡/低/极低分别最多约 829/369/207/92 万像素，不改变所选档位或默认选择。小屏不额外放大。
- 平衡档 Bloom 使用半尺寸输入、相同强度/阈值/半径；所有 Bloom 中间目标不再申请深度缓冲。高档保留完整 Bloom 尺寸；低和极低仍关闭 Bloom。
- 启动、切换画质、窗口/全屏/横竖屏变化共用同一尺寸策略；调整水面捕获尺寸后强制下一帧更新，防止沿用旧投影。
- 天空移到不透明物体之后，以远平面深度接受屋顶遮挡；透明水面/天窗玻璃仍在其后绘制。
- 采用 Pool 四侧远雾边界，跟随分块窗口并匹配水下颜色，顶部保持开放。保留冰馆原有雾密度，避免改变近处物证的可见距离；不引入 Pool 的整套设置或雾强度滑杆。边界不参与碰撞，退出时释放。
- 音频关键声池逐池轮转优先下载/解码并逐步可播，首批并发同时覆盖走路、跑步和两类水花，避免一整组脚步阻塞首个水花，后台 `loading` 仍等待全量素材完成；迟到结果不会复活已销毁系统。池内顺序固定，去重按采样身份而非会漂移的数组下标。
